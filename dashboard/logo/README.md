# Logo emiten

Dashboard mencari logo dengan urutan: (1) file `dashboard/logo/<KODE>.png`, (2) URL di kolom `logo` pada `dashboard/assets/emiten_logo.js`, (3) ikon situs resmi lewat layanan favicon Google, (4) lencana inisial.

Cara memasang logo resmi: buka tautan situs resmi atau pencarian logo, unduh gambar PNG (sebaiknya latar transparan, persegi), lalu simpan di folder ini dengan nama kode saham, misalnya `ANTM.png`. Muat ulang dashboard.
